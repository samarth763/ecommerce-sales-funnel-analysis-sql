# E-Commerce Sales Funnel & Revenue Analysis Using SQL

## Overview

This project analyzes an e-commerce customer journey using **PostgreSQL**. It focuses on sales funnel performance, conversion rates, traffic sources, customer journey time, and revenue.

## Analysis Covered

* Sales funnel stage analysis
* Conversion rates between funnel stages
* Funnel performance by traffic source
* Time from view → cart → purchase
* Total customer journey time
* Revenue and Average Order Value (AOV)
* Revenue generated per visitor

## Tools Used

* PostgreSQL
* SQL
